## 5. 关于「查证源码」

Steam 商业游戏**不随安装包发行原始码**。此目录内 `Taiko5DX.exe` 等为**编译后二进位**（PE，经 KOEI 签章），`data/` 为打包资产，再叠 Steam DRM（steam_api / SteamStub）。**没有源码可查**；要「看源码」须反编译 + 解密 DRM＝规避版权保护，违反 EULA 与反规避法，**本报告不为之**。合法可做的是：机制黑箱研究 + 独立实现（见仓库《大秦赋》§机制参考）。

## 6. 错误诊断：Application load error 3:0000065432

档案既正品完整，病因在**启动时 DRM 初始化**，可能性由高到低：

1. **首次启动的管理员安装脚本（DirectX）未完成**——UAC 预设在「否」，若按下「否」，DirectX/前置未装好，DRM 启动失败。
2. **Steam 未以管理员执行**——runasadmin 脚本与 DRM 需足够权限。
3. **安全软体 runtime 挂钩**（本机 Kaspersky + 亿赛通 CDG + 天锐绿盾）在**行程载入时**拦截游戏 exe / steam_api——档案在磁碟上没事，但执行被挂起。符合本机「不在名单上的应用会被管控软体弄坏」的既有纪录。

## 7. 建议解法（逐一实测，第一个能进游戏即止）

1. **以系统管理员执行 Steam** → 再启动太阁（右键 Steam →以管理员身分执行）。
2. 下次弹 UAC 安装脚本时**按「是」**，让 DirectX 前置装完。
3. Steam →太阁→内容→**验证游戏文件完整性**（会补回任何被挡/缺失档）。
4. 仍失败 → 多半是 **Kaspersky/亿赛通/天锐在 runtime 挡 exe/steam_api**：**归 IT**，请对
   `…\steamapps\common\Taiko5DX\Taiko5DX.exe`、`Taiko5DXLauncher.exe`、`steam_api*.dll`
   加白名单（**不自行停用资安软体**）。
5. 可另手动安装 DirectX End-User Runtime 后重试。
