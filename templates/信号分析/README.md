# 信号分析模板：从量化到传感器/脑机信号

同一套管线——**信号 → 去噪 → 特征 → 模型 → 验证**——量化交易和传感器/脑机信号是通用的。
这两个脚本用本仓库已建好的 Python 环境（`C:\work\envs\ds`，742 套件）跑，无需额外硬件。

实测环境：Python 3.13.15、mne 1.13.2、scikit-learn 1.7.2、scipy 1.18.1。

## 1. `eeg_运动想像分类.py` — 真实脑电，想像左手 vs 右手

- **数据**：PhysioNet EEG Motor Movement/Imagery（公开，mne 首次运行自动下载约 7.5 MB）
- **管线**：原始 EEG → 带通 7–30 Hz（mu+beta 频带）→ CSP 空间滤波特征 → LDA → 十折交叉验证
- **实测结果（受试者 1，2026-09-23）**：

  | 指标 | 值 |
  |---|---|
  | 瞎猜基线 | 44.4% |
  | CSP+LDA | **61.1%（± 14.3%）** |

- **这个数字的意义**：远高于瞎猜（脑电确实含「想动哪只手」的信息），但远低于「读心」。
  单受试者、少量数据只有六成且抖动大。要到 70–85% 需更多受试者/数据/更优时窗。
- **坑（已修）**：`eegbci.load_data` 首次会**交互式询问**是否设默认路径，非交互环境会卡死；
  必须传 `update_path=True`。

## 2. `加速度_动作识别.py` — 三轴加速度，走/跑/静止

- **数据**：物理建模的合成信号（走~2Hz、跑~3Hz、静止无周期）。**这是占位数据。**
- **管线**：分窗（2 秒/50% 重叠）→ 时域(均值/标准差/IQR/RMS)+频域(主频/占比/谱质心) → RandomForest → **GroupKFold 按 session 分组**验证
- **实测结果**：瞎猜 33.3% → RandomForest **100.0%**
- **这个 100% 是反面教材**：不是模型强，是合成数据太干净、三类分得太开。
  真实手机 HAR 通常 90–97%。**准确率满分时先怀疑数据，别庆祝模型。**
- **换成真实数据**：手机装一个能导出 CSV 的加速度记录 App，走/跑/静止各录几段，
  替换脚本里的 `gen_session()` 读你的 CSV 即可。届时数字才有参考价值。

## 通用原则（两个实验共同的教训）

1. **验证方式比模型更重要。** B 的 GroupKFold 防的是「同一段数据同时进训练和测试」的泄漏——
   等同于量化里防前视偏差（look-ahead bias）。
2. **固定随机种子**，结果可复现（两脚本都设了 `random_state`/`rng`）。
3. **永远先建瞎猜基线**，再看模型高出多少。孤立的准确率数字没有意义。
4. **合成/过易的数据会骗你**（B 的 100%）；**真实数据会让你看清边界**（A 的 61%）。
