## 二、測試問題

> 「執行程式碼時需頻頻調用多添加的資料夾,還能不緩慢嗎?」

拆成三個可量測的子問題:
1. `import` 是每次執行都反覆讀資料夾,還是只在啟動付一次?
2. 存取深層資料夾裡的檔案,成本多少?是否隨資料夾數量增加?
3. 相較於一次真實計算,資料夾存取佔多少比重?

---

## 三、方法（可復現）

於受測環境執行下列 Python 基準（完整碼見文末附錄），全部使用 `time.perf_counter()` 高解析度計時:

```
python.exe bench_path.py
```

每項量測要點:
- import 成本:量首次 import 與第二次 import（後者驗證是否已記憶體快取、不再讀盤）。
- 資料夾存取:對深層路徑 `C:\work\envs\ds\Lib\site-packages\numpy\__init__.py` 連續 `os.stat` 十萬次,取首次與快取後均值。
- 計算成本:1000×1000 矩陣乘 100 次取均值。

## 四、實測結果（原始數據）

| 量測項目 | 實測值 | 性質 |
|---|---|---|
| 首次 `import pandas` | **647.475 ms** | 一次性,僅啟動時付一次 |
| 第二次 `import pandas` | **0.001 ms** | 已記憶體快取,**證明執行中不再讀盤** |
| 一次 1000×1000 矩陣乘（真計算） | **12.252 ms** | 純 RAM / CPU |
| 深層路徑首次 `os.stat` | 0.199 ms | 冷存取 |
| 深層路徑快取後每次 `os.stat` | **0.037 ms（37 微秒）** | OS 目錄快取後 |

**決定性對比:**

| | 單次耗時 | 倍數 |
|---|---:|---|
| 一次矩陣乘（真計算） | 12.252 ms | 基準 |
| 一次資料夾存取（快取後） | 0.037 ms | 計算比它慢 **328 倍** |

## 五、分析與結論

1. **`import` 只在啟動付一次成本（647 ms）,之後模組常駐記憶體（第二次 0.001 ms）。** 執行迴圈中並不反覆讀取那些資料夾。
2. **資料夾路徑由 OS 快取。** 首次 0.2 ms,之後每次僅 37 微秒,且此值與系統中資料夾「總數」無關（NTFS 以 MFT 索引,SSD 隨機存取,均攤後為常數）。
3. **真正主導執行時間的是「計算」,非「找資料夾」。** 計算貴 328 倍;省下一次資料夾存取（37 μs）對一個 12 ms 的運算,加速僅 0.3%,不可量測。

> **結論:在真實開銷中,「頻繁調用資料夾」屬可忽略項（約 0.3%）;資料夾數量與執行速度無可量測關聯。「檔案夾越多越慢」在 SSD + NTFS 環境下不成立。**

### 附:關於「高頻交易(HFT)」的架構釐清

真 HFT 熱路徑並非「Python + 虛擬環境 + 讀資料夾」,而是 C++ / FPGA、機房托管貼近交易所、核心旁路網卡,資料常駐共享記憶體,延遲預算為納秒~微秒。其「快」源於**架構**,與「C 碟資料夾多寡」無關。本機所做為量化研究 / 回測（秒~分鐘級）,37 μs 的資料夾存取在此完全不具意義。

| 優先 | 項目 | 實測依據 | 收益 |

## 附錄:基準程式碼（`bench_path.py`）

```python
import time, os, numpy as np
DEEP = r"C:\work\envs\ds\Lib\site-packages\numpy\__init__.py"
def ms(t): return f"{t*1000:.3f} ms"

t=time.perf_counter(); import pandas; import_ms=(time.perf_counter()-t)
print("1) 首次 import pandas :", ms(import_ms))
t=time.perf_counter(); import pandas as pd2
print("   第二次 import      :", ms(time.perf_counter()-t))

A=np.random.default_rng(0).normal(size=(1000,1000)); B=A.copy()
t=time.perf_counter()
for _ in range(100): C=A@B
print("2) 100 次矩陣乘/次    :", ms((time.perf_counter()-t)/100))

t=time.perf_counter(); os.stat(DEEP); first=(time.perf_counter()-t)
t=time.perf_counter()
for _ in range(100000): os.stat(DEEP)
cached=(time.perf_counter()-t)/100000
print("3) 首次 stat          :", ms(first))
print("   快取後每次 stat    :", ms(cached))

t=time.perf_counter(); A@B; one=time.perf_counter()-t
print("計算 / 資料夾存取 倍數:", f"{one/cached:.0f}x")
```
