# 持续诊断面板验收

- 新增 Watch-LocalDiagnostics.ps1，原五个脚本未修改。
- Windows PowerShell 5.1与PowerShell7：各两轮运行，开启变化快照，退出码均为0。沙箱查询限制明确显示为警告。
- 沙箱外PowerShell7：两轮运行退出0，成功展示本机系统、键盘、TCP连接关联进程；输出live.txt。
- 不进行远端扫描，不推测设备或系统信息，不采集按键内容，不修改驱动、安全设置或启动项。
- 默认每轮后等待5秒；静态清单每60秒更新；连接最多2000条，明确显示截断；可选快照固定10个文件槽，每文件不超过1MiB。
- 有限测试不能证明无限期运行无退化；尚未实测长期资源曲线、人工中断和日志槽全部轮替。无证据确认所谓监控方身份。
