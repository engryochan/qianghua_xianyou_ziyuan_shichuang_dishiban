# 跨域策略平臺調研：地緣、金融、農牧漁、消費百業、宇航軍工

日期：2026-10-11
性質：外部資料調研（網路查證），非本機實測。
**所有斷言都標明來源與界限**；查不到的照實說查不到。

---

## 零、先講結論：**沒有單一平臺涵蓋全部領域**

先生列的範圍（地緣學、金融商業、農牧漁業、百業銷售與日常消費、宇航軍工國防）
跨越五個彼此資料結構迥異的領域。**查證結果是：市面上沒有任何一家做到全覆蓋。**

最直接的證據來自競品分析本身——針對 Palantir 的 2026 年競品研究指出，
**沒有單一對手能覆蓋 Foundry + Gotham + AIP 的完整堆疊，買方通常是從數家
供應商拼裝替代方案**。而 Palantir 自己真正短兵相接的只有三塊：企業 AI、
國防資料整合、政府認證。

> **所以正確的問法不是「哪一個平臺」，而是「哪一層用誰，怎麼接起來」。**
> 下面按層分述。

**另有一條必須先說的方法論警告**：本次查到的多數比較文章是
**供應商自撰或聯盟行銷性質的清單**（Stardog 與 DataWalk 本身就賣競品，
部分條目是付費曝光），**排名不可當真**。真要採購應看 Gartner／Forrester
並拿自己的資料實測。

## 一、整合層（真正意義上的「策略平臺」）

這一層負責把異質資料接成本體論（ontology）並驅動決策。

| 平臺 | 定位與現況 |
|---|---|
| **Palantir Foundry + Gotham + AIP** | **唯一同時橫跨商業與國防的**。Foundry 偏企業營運，Gotham 偏情報與調查，AIP 是 LLM 編排層 |
| **Microsoft Fabric** | 被視為**商業面最大威脅**，靠綁進既有 Azure 合約。但**其 ontology 與語意能力至 2026 年 9 月仍是 preview** |
| **Databricks** | 常被評為整體最強替代，Unity Catalog（治理）+ Mosaic AI |
| **Snowflake** | BI 與資料科學團隊的彈性替代 |
| **C3.ai** | 企業 AI 一塊 |
| **DataWalk** | 與 **Gotham** 的情報／調查／實體分析重疊度最高。其「功能相當而成本更低」是**自家行銷說法，需獨立驗證** |
| **ChapsVision Argonos** | 主權（sovereign）情報選項，歐洲 |

> **值得注意的結構性事實**：許多 Foundry 部署其實**架在 Databricks 或
> Snowflake 之上**，所以這幾家既是競爭者也是夥伴。

## 二、地緣 / 地理空間層

| 平臺 | 說明 |
|---|---|
| **Planet Labs** | 高頻率全球光學覆蓋（每日重訪） |
| **Maxar** | 高解析光學，國防與情報老牌 |
| **ICEYE** | SAR（合成孔徑雷達），**可穿雲、夜間可用**，洪災與軍事監測 |
| **EarthDaily Analytics** | **2024-10-15 併購 Descartes Labs**，兩家同屬私募 Antarctica Capital。產品 **Marigold / Iris / Ascend**，服務礦業探勘、保險、商品交易 |
| **Spire** | 原有船舶追蹤與氣象。**其 Maritime 業務已由 Kpler 以 2.41 億美元併購**（見下節） |

**Descartes Labs 特別值得一提**，因為它正好是「地緣 × 農業 × 金融」的交匯點：
它起家於**用衛星影像、氣象等資料在收成前六個月預測美國玉米與大豆產量**的農業
模型，客戶橫跨農業與商品交易商、礦業、保險、能源，以及**美國國防機構**。
一份 2026 年 6 月更新的側寫仍描述該公司為營運中。

## 四、商品／航運／能源層（**實際上的跨域樞紐**）

這一層最有意思，因為它天然把**地緣政治 → 實體流動 → 金融價格**串起來，
而且**近兩年整併最劇烈**。

| 平臺 | 2026 年現況（已查證） |
|---|---|
| **Kpler** | **四家中最活躍**。已併購：**Spire Maritime（2.41 億美元）**、MarineTraffic 與 FleetMon（2023-02）、ClipperData（2021-09，帶來全球原油、穀物與精煉品流向資料）、**Citac（2026-05，非洲下游能源市場情報）**。**2026-06 獲 Sixth Street 策略成長投資** |
| **Vortexa** | 能源市場情報與貨載追蹤，英國 SaaS，能源流分析與運費定價。企業價值約 5 億美元級 |
| **S&P Global Commodity Insights**（Platts） | 另**買下 ORBCOMM 的海事衛星 AIS 資料業務** |
| **Argus Media** | 價格評估 |

**兩點要留意：**

1. **Kpler 的農業覆蓋主要來自穀物流向資料，不是衛星作物預測**——
   若需要後者，要配 EarthDaily／Descartes Labs。
2. **Spire 出售給 Kpler 曾被其船舶追蹤客戶提出反壟斷顧慮。**
   這一層的資料來源正在收斂到少數幾家手上，**是採購上的集中風險**。
3. 我**未查到** Kpler 與 Vortexa 合併的任何證據；有來源仍將兩者列為競爭對手，
   應屬各自獨立。

> **這一項我刻意留白而不補齊。** 一個「曾經是該領域代表、現在可能已不存在」
> 的名字，寫進清單比不寫更危險。

畜牧與水產的專門平臺在本次查證中沒有浮現具規模者；這一塊**相對於其他領域
明顯薄弱**，多由農業平臺附帶處理。

## 六、百業銷售、起居飲食、日常消費層

- **NielsenIQ**：零售量測
- **Circana**：由 **IRI 與 NPD 合併**而成，消費品與耐久財
- **Kantar**：品牌與消費者研究
- **Similarweb**：數位流量
- **Placer.ai**：**實體人流**（手機定位推估），零售選址

此層與上面各層的整合度最低——**消費資料幾乎自成一個生態，很少與地緣／國防
平臺打通**。這是先生所列範圍裡最明顯的斷點。

## 八、對本機的實話：上述平臺都不是這台機器能跑的

**必須把調研結果接回現實。** 上述幾乎全部是**企業級訂閱平臺**，
年費動輒六至七位數美元，且本機是：

- **受管理的公司資產**（三層 DLP／AV 常駐）
- **32 GB RAM、無任何推論加速器、單顆 238 GB SATA SSD、目前可用約 34 GB**
- 升級後連 Kaspersky 都還沒修好

**所以真正可行的路徑，是用開放資料 + 本機既有的 R／Python 堆疊自建。**
而且本機**已經裝好了相當一部分**：

| 領域 | 開放／低成本來源 | 本機現況 |
|---|---|---|
| 金融商業 | **OpenBB**、yfinance | **已裝**於 `C:\work\envs\fin`（含 `openbb-platform-api`、`pyportfolioopt`） |
| 地理空間 | Google Earth Engine、Sentinel Hub、STAC + `rasterio`／`rioxarray` | 核心環境已有 geo 相關套件 |
| 總體經濟 | FRED、World Bank、UN Comtrade | 可用 `pandas-datareader` 等 |
| 地緣衝突 | **ACLED**、**GDELT**、**SIPRI**（軍費） | 皆為公開資料集 |
| 航運 | 開放 AIS、**Global Fishing Watch** | 公開 API |
| 因果推論與決策 | `econml`、`dowhy`、`dalex` | **已裝**（`dalex` 在 `xai` 衛星環境） |
| 時序與預測 | `sktime`、`gluonts`、CmdStan | **已裝**（`gluonts` 在 `rl` 衛星環境；CmdStan 已編譯可用） |

> **這正是本倉庫既有架構的價值所在。** 先生問的那種「集多域為一體的策略平臺」，
> 商業上是拼裝出來的；而本機這套**核心 + 五衛星 + R + CmdStan + Quarto**
> 已經具備自建分析層的能力，缺的是資料接入與本體論設計，不是算力或工具。

## 九、本次調研的界限（務必一併看）

1. **多數來源是供應商自撰或聯盟行銷清單**，排名不可當真；Stardog、DataWalk
   等本身賣競品，部分條目為付費曝光。
2. **Gro Intelligence 的現狀未能查證**，已在第五節明確標註。
3. **未查證**：各平臺的實際定價、是否對華夏地區供應、以及公司資安政策是否
   允許接入。這三項對本機而言是比功能更前置的門檻。
4. 本節所有內容**皆為外部資料調研，非本機實測**，與本倉庫其他報告的證據等級
   不同，不應混為一談。
