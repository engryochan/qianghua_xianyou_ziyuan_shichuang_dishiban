## 三语 README 校对

1. 三份文件均说明默认存档位置 `%USERPROFILE%\Documents\KoeiTecmo\Taiko5DX\SaveData`，由 Steam 提供更新，以及启动器可打开说明书。实际 Documents 可被 OneDrive 重定向，默认路径说明不替代实际位置验证。
2. 简体版“安装 DirectX 最新版本”的表述不够精确：日文原文和繁体版明确指 DirectX End-User Runtime，三版链接均为微软下载 ID 35。微软说明该安装器补充旧 SDK 的并行运行库，不改变 Windows 自带的 DirectX 版本。主程序导入的 XINPUT1_3.dll、D3DCOMPILER_43.dll 与这种旧组件依赖一致。本轮检查两者在对应系统目录存在，但没有重新安装或加载它们。
3. 文档涉及关闭常驻/安全软件的泛用建议，不适用于本公司政策，未执行。不能仅因文档提到后台软件便确诊启动失败由安全控制造成。
4. 三版卸载/快捷方式菜单描述有本地化和旧 UI 差异；日文 README 的 ver1.00 是文档版本标记，不能拿它认定当前游戏 EXE 应为 1.00 或有版本损坏。没有修改原始 README 来“纠正”翻译。
5. 文档对性能的建议是条件性描述，不提供本机的 FPS、延迟或功能验收证据。当前没有证实所有游戏功能可运行。

## 尚需完成才能称为“全部内容已验证”的工作

- 对每类专用容器取得可靠格式说明或经过验证的读取器，再检查内部对象数量、边界、类型、字段和交叉引用；文件头家族/整数观察不能替代这些工作。
- 对所有图像、字体、声音和影片实现实际解码与内容审阅；对全部事件逐条解析条件、动作、标识与语言对应关系。
- 解决或明确当前 Steam 加载错误，之后才能在正常授权环境验证游戏/事件转换器运行与实际文件访问。此阶段可能正常产生日志、配置或存档；不能在“运行任何程序但保证任何文件绝不变化”这个前提下执行。
- 完整功能测试需要覆盖游戏状态与路线，不可能用“每个文件读取一次”证明所有职业、交易、AI 决策和事件组合正确。现阶段也没有恢复开发者完整源码。

上述未完成事项没有被假报为 PASS。本轮没有启动游戏或转换器、修改/删除游戏文件、移除 DRM、替换 DLL、修改地区或触碰公司安全策略。
