# 2026-09-23 键盘模板实测

范围：诊断电脑模板下全部五个 PowerShell 脚本；原稿保存在 before/。

修复：RawInputKeyLogger 原 C# 编译方式错误，改为复用修正后的 Raw Input 入口；解决 NativeWindow.Handle 名称遮蔽和 PowerShell 7 WinForms 引用；增加时长范围、默认自动退出、计时器及窗口清理、钩子清理、重复运行统计重置、串行日志写入、错误传播。预检逐项独立，失败不再跳过其余检查。全部代码行使用前置 PowerShell 注释或 C# 行注释；here-string 边界独占一行以保持合法语法。

功能保留：五个入口仍在；全键位显示及键码记录需显式使用开关。默认减少敏感内容落盘。没有修改驱动或系统安全设置。

验证结果：

- results.json：两个运行时共 16 项编译/实际运行测试全部退出 0，包括全部五个脚本的 1 秒实际运行。
- validation-ps51.txt、validation-ps7.txt：五个脚本语法解析及零时长拒绝通过；低级钩子与 Raw Input 在同一进程各重复运行两次通过，输出 VALIDATION_OK。
- validation-unrestricted.txt：沙箱外重复上述验证通过，用于核实设备与进程读取权限。
- 沙箱内设备与进程查询受限，辅助功能与输入法读取成功。错误被单独记录，未伪装成空清单。
- 短时测试未采到真实按键事件；默认日志键码检查在空日志上通过，不能代替有事件的隐私验证。尚未验证故障复现、实体/屏幕键盘对照、恶意输入归因或所有退出中断方式。

本次证据支持可运行性、兼容性与退出流程改善；没有足够证据承诺所有工作负载绝无退化，也没有证据认定键盘被入侵。脚本不具备读取思维或访问另一台设备日志的能力。
