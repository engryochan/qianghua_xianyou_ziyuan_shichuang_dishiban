# 太阁立志传Ⅴ DX：地区、错误码与源码核查

核查日期：2026-10-02。本轮只读核查，未修改地区、代理、游戏文件、公司安全策略，也未代为再次启动游戏。

## 结论

尚未证实 `Application load error 3:0000065432` 的唯一原因，也未找到将此代码映射到 Steam 内部函数的公开官方对照表。不能据此宣布是地区封锁或某个安全产品拦截。

## 本机实读

`region-settings.json`：Windows 国家/地区：中国（GeoId 45）；区域格式与系统区域：zh-CN；时区：Georgian Standard Time；Steam 界面语言：schinese。这些不是 Steam 账户的商店国家。没有读取账户登录凭据或付款资料，商店国家及购买许可证的运行区域限制尚未确认。

Steam 控制台日志在 15:42:41（本机时间）记录 `steam://launch/1842810/Dialog`，15:42:43 创建 Taiko5DXLauncher.exe，15:42:54 移除该进程；游戏进程日志记录退出码 51。该网页操作仍走 Steam 本机启动链。没有证据将退出码 51 或用户统计请求响应 2 等同于弹窗中的复合错误码。

## 网页核查及局限

官方游戏网站指向 Steam App ID 1842810。本轮外部网页工具读取 `https://store.steampowered.com/app/1842810/` 返回 `This item is currently unavailable in your region`；读取用户给出的 `https://store.steampowered.com/app/1842810/V_DX/` 却返回正常商品页及购买入口。两者同属 App ID 1842810；请求结果不同，未查明是否涉及请求地区、会话或缓存。网页工具的出口及会话不代表用户本机，不据此推断用户账号所在地。

正常商品页列出简体中文、繁体中文、日语和 Windows 10/11 64 位支持。因此 zh-CN 及 Windows 11 本身没有显示为不支持条件。这也不证明许可证、安装文件或企业策略完全正常。

Steam 官方说明账户商店国家可在账户明细查看；地区限制另有官方说明。销售可用性、语言支持、许可证运行限制和本机程序加载失败须分别验证。

## 错误字典与函数

本轮未找到 Valve/Steamworks 公开发布的 `3:0000065432` 唯一含义或源码函数映射。不能把该复合代码当作 Windows Win32 错误编号查表。

Excalibur 对另一款游戏的同一错误码列出安全软件阻止执行、文件或 Steam 安装异常等可能原因；这是候选原因，并不是本机太阁的确诊。此前本机调查未找到明确匹配游戏的阻止规则或事件；Kaspersky 报告目录不可读，需 IT 控制台核对，不能绕过权限。

Steamworks 的 `SteamAPI_Init()` 文档列出客户端未运行、App ID 未确定、游戏与 Steam 的操作系统用户/权限不同、许可缺失等初始化失败条件，但文档未将这些条件或该函数映射到此弹窗代码。函数真实来源需 Valve/发行商的内部符号、调试信息或支持记录确认。

## 源码边界

保存的文件清单中，Steam 有 368 个 `.js` 文件；这些是发布版界面脚本，不是完整客户端源码工程。候选开发文件扩展名搜索未发现完整 C/C++ 等工程；这不是对所有二进制内容的解密或反编译。

针对 Steam 的 steamui/resource/public 中可读 JS、TXT、JSON、VDF、HTML、XML，字面搜索 `0000065432` 和 `Application load error` 返回 0 项。搜索范围不包括二进制反汇编；没有匹配不能证明二进制不存在此字符串。

公开 Steamworks API/SDK 说明和接口不等于 Steam 内部加载器实现；也不等于太阁游戏源码。之前游戏文件盘点未找到常见源码工程，不能因此断言资源包加密。
